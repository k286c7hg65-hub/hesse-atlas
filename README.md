## 怎么用

- 左右翻页：点底部箭头、键盘 ← → 或空格、手机上左右滑动
- 跳页：点"目录"选章节，或点底部缩略图/圆点
- 放大看细节：点页面任意处，滚轮/双指缩放，拖拽移动，双击放大，Esc 退出
- 桌面端自动双页展开，手机/平板自动单页纵向阅读
- 打印：右上"打印"，每页一图输出

## 技术

单文件 `index.html`，无框架、无外部 CDN，图片为 WebP（全册约 2.4 MB，含模糊占位图首屏秒开）。
含 `prefers-reduced-motion` 降级、键盘可访问、`aria-live` 页码播报、`@media print` 打印样式。
